Developed an autonomous robot using Arduino and ultrasonic sensors for real-time obstacle detection and navigation. Implemented motor control logic to dynamically change direction and avoid collisions without human intervention.
# 🚗 Obstacle Avoiding Robot (Arduino)

## 📌 Overview

This project is an autonomous robot that detects obstacles using an ultrasonic sensor and navigates accordingly.

## ⚙️ Components Used

* Arduino Uno / ESP32
* Ultrasonic Sensor (HC-SR04)
* Motor Driver (L298N)
* DC Motors
* Power Supply

## 🔧 Working

* The ultrasonic sensor measures distance from obstacles
* If obstacle is detected → robot changes direction
* Else → moves forward

## 🧠 Features

* Real-time obstacle detection
* Autonomous navigation
* Simple and efficient logic
